#ATIVIDADES DO PROFESSOR KENYO#

##Neste repositório contém as resoluções das listas de exercícios passadas pelo professor!##
##O objetivo principal é praticar a lógica + estruturas de dados, sem o uso de IA.##

- 1. Soma de Elementos em um Array: Crie um programa que recebe um array de
números inteiros e retorna a soma de todos os seus elementos.

- 2. Verificador de Palíndromo: Escreva uma função que recebe uma string e determina se
ela é um palíndromo (ou seja, se pode ser lida da mesma forma de trás para frente,
como "arara"). A verificação deve ser case-insensitive e ignorar espaços.

- 3. Contador de Vogais: Crie um programa que recebe uma string e conta quantas vogais
(a, e, i, o, u) ela contém. A contagem deve ser case-insensitive.

- 4. Encontre o Segundo Maior Elemento: Desenvolva um programa que encontra o
segundo maior número em um array de inteiros. O array pode conter números
duplicados. Você não pode usar nenhuma função de ordenação nativa.
