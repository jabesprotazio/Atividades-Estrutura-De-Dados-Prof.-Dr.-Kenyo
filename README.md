##Neste repositório contém as resoluções das listas de exercícios passadas pelo professor!##
##O objetivo principal é praticar a lógica + estruturas de dados, sem o uso de IA.##

#Exercícios de Estruturas de Dados - Revisão
- 1. Soma de Elementos em um Array: Crie um programa que recebe um array de
números inteiros e retorna a soma de todos os seus elementos.

- 2. Verificador de Palíndromo: Escreva uma função que recebe uma string e determina se
ela é um palíndromo (ou seja, se pode ser lida da mesma forma de trás para frente,
como "arara"). A verificação deve ser case-insensitive e ignorar espaços.

- 3. Contador de Vogais: Crie um programa que recebe uma string e conta quantas vogais
(a, e, i, o, u) ela contém. A contagem deve ser case-insensitive.

- 4. Encontre o Segundo Maior Elemento: Desenvolva um programa que encontra o
segundo maior número em um array de inteiros. O array pode conter números
duplicados. Você não pode usar nenhuma função de ordenação nativa.

- 5. Inversão de Palavras em uma Frase: Escreva uma função que recebe uma string
representando uma frase e inverte a ordem das palavras nela. Por exemplo, a frase "Olá
mundo" deve se tornar "mundo Olá". A pontuação e a capitalização devem ser
preservadas.

- 6. Filtrar Números Pares: Crie um programa que recebe um array de números inteiros e
retorna um novo array contendo apenas os números pares do array original.

- 7. Busca de Elemento Faltante: Você recebe um array contendo n-1 números inteiros,
que são um subconjunto de todos os números de 1 a n. Um número está faltando.
Encontre o número que falta.

- 8. Primeiro Caractere Não Repetido: Escreva uma função que encontra o primeiro
caractere não repetido em uma string. Por exemplo, se a string for "stress", a resposta
deve ser "t".

- 9. Soma de Pares: Dado um array de números inteiros e um número-alvo, encontre dois
números no array cuja soma seja igual ao número-alvo. Retorne os índices desses dois
números. Considere que haverá exatamente uma solução e que você não pode usar o
mesmo elemento duas vezes.

- 10. Combinar Arrays Ordenados: Você tem dois arrays já ordenados. Escreva um
programa que combine esses dois arrays em um único array, também ordenado, de
forma eficiente. Não use funções de ordenação nativas após a combinação.
